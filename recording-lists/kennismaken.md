# Recording list — Kennismaken (Faire connaissance)

Read each line naturally, at a calm everyday pace, in Flemish as you would say it to a colleague.
Save each file as `app/audio/kennismaken/<file>.m4a`. Ticked lines are already recorded.

## Words and phrases

| | File | Say | Meaning |
|---|---|---|---|
| ⬜ | `hallo` | **Hallo!** | Bonjour ! / Salut ! |
| ⬜ | `goeiedag` | **Goeiedag!** | Bonjour ! (poli) |
| ⬜ | `dag` | **Dag!** | Salut ! / Au revoir ! |
| ⬜ | `ik-heet` | **Ik heet** | Je m'appelle … |
| ⬜ | `hoe-heet-u` | **Hoe heet u?** | Comment vous appelez-vous ? |
| ⬜ | `aangenaam` | **Aangenaam.** | Enchanté(e). |
| ⬜ | `hoe-gaat-het` | **Hoe gaat het?** | Comment ça va ? |
| ⬜ | `goed-dank-u` | **Goed, dank u.** | Bien, merci. |
| ⬜ | `ik-kom-uit` | **Ik kom uit** | Je viens de … |
| ⬜ | `ik-woon-in` | **Ik woon in** | J'habite à … |
| ⬜ | `een-beetje` | **Ik spreek een beetje Nederlands.** | Je parle un peu néerlandais. |
| ⬜ | `tot-ziens` | **Tot ziens!** | Au revoir ! |

## Dialogue — Op het werk — Au travail

Two voices if possible: one person reads Sofie, another reads Karim.

| | File | Who | Say |
|---|---|---|---|
| ⬜ | `d01` | Sofie | Goeiedag! Ik heet Sofie. Hoe heet u? |
| ⬜ | `d02` | Karim | Dag Sofie, ik heet Karim. Aangenaam. |
| ⬜ | `d03` | Sofie | Aangenaam. Waar woont u? |
| ⬜ | `d04` | Karim | Ik woon in Brussel, maar ik kom uit Luik. |
| ⬜ | `d05` | Sofie | Ah, u spreekt Nederlands! |
| ⬜ | `d06` | Karim | Een beetje… |
| ⬜ | `d07` | Sofie | Heel goed! Tot straks, Karim. |
